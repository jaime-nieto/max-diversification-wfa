Each window: weights fitted on 504 trading days, then held for the next 252. Both DR columns use the plain sample covariance of the window they refer to and the weights set at the start of the out-of-sample window. All three portfolios use the same eligible stocks. The last, incomplete window is excluded. 'In blocks': the in-sample window is cut into consecutive blocks of 252 days and the DR of each block is averaged, so that in-sample and out-of-sample are measured over the same horizon; 'like for like' divides the out-of-sample DR by it.
